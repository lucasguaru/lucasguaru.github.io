# Contexto do repositório

- Este repositório é o GitHub Pages pessoal do usuário.
- Cada pasta na raiz representa um projeto ou uma página independente.
- Quando o usuário pedir para criar um novo projeto, página ou experiência, crie uma nova pasta na raiz do repositório e mantenha todo o conteúdo desse projeto dentro dela.
- Não misture os arquivos de um novo projeto com os de outras pastas existentes, salvo quando o usuário pedir explicitamente por recursos compartilhados.
